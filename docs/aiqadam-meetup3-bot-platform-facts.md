# Бот и Qadam Flow — факты и цифры для сцены

Всё проверено на живом проде и в репозитории (срез 16.10.2026).
Готовые формулировки для слайдов — в конце.

## 1. Бот в цифрах

- **30 флоу** — вся функциональность: регистрация, QR-билеты, сканер-чекин,
  квиз, рассылки (с сегментами и дожимом), напоминания, меню, профиль,
  согласия, стафф-инвайты, отчётность
- **519 шагов** внутри этих флоу: 328 действий платформы, 133 Code step,
  44 развилки (ROUTER), 14 циклов
- Собственных сервисов — **0**. Внутри Code steps — ~**5 100 строк** кода,
  и это только чистые функции-склейки (без сети и записи в БД)
- Что дёргают шаги чаще всего: **tables ×172**, **telegram-bot ×58**
  (сообщения и работа с Telegram API), **webhook ×48** (вызовы из Mini App),
  **subflows ×39** (внутренние «функции»), store ×3, crypto ×3, http ×3, delay ×2
- **20 таблиц** в проде, главные: users, registrations, events, broadcasts,
  broadcast_targets, quiz_answers
- **323 записи в migrations** — полный аудит всех изменений системы
- Mini App — React SPA из **6 экранов**: билет, сканер, управление, каталог
  событий, отзыв, отчёт

## 2. Разработка в цифрах

- Бот начат **8 сентября** — за 5 недель до митапа
- **921 коммит** (≈27 в день)
- **123 пакета работ** — каждый с чек-листом готовности; сданный пакет
  проходит **независимое ревью отдельным агентом** с чистым контекстом,
  и только потом «готов». Сам себе сдать нельзя
- **53 ADR** — каждое спорное решение записано: почему именно так
  (отказ от atomic-примитивов, запрет команд кроме /start, «0 кода»…)
- **63 000+ строк документации** (ТЗ, архитектура, каталог, журналы работ)
- Юнит-тестов нет — их роль выполняют: независимое ревью + **5 офлайн-проверок**
  в tools/ (секреты, тексты, команды, миграции, роли) на каждом коммите
- Выгрузка флоу в git: **19 314 строк JSON** (~1,2 МБ) — репозиторий хранит
  ровно то, что стоит на проде

## 3. Платформа Qadam Flow в цифрах

- Лимиты: прогон флоу — **600 секунд**, триггер — **60 секунд**.
  Поэтому рассылка нарезана на чанки с курсором: длинная кампания
  продолжается итерациями, а не висит одним прогоном
- Цена шага (замеры на этом же инстансе):
  - ROUTER — **0,03 мс**
  - Code step — **2–5 мс**
  - чтение/запись tables — **25–70 мс**
  - отправка сообщения в Telegram — **0,7–0,9 с** ← единственная дорогая операция
- Практический вывод: экономить на шагах бессмысленно, экономить надо
  на **количестве сообщений** — поэтому при /start бот отвечает одним
  аккуратным сообщением-меню, а не тремя
- Бот работает на **long-polling**, а не вебхуке Telegram — эксклюзивность
  токена та же, зато не нужен публичный endpoint
- Идемпотентность без транзакций: защита от дублей — через **store**
  (`put_if_absent`): один `update_id` Telegram = одна реакция, повторный
  чекин показывает исходное время, повторная регистрация не сбрасывает данные
- Криптография платформенная: HMAC-подпись QR-билетов — qadam `crypto`,
  проверка подписи — узкое разрешённое исключение (node:crypto внутри функции)
- Code steps исполняются в **полноценном Node** — доступны `node:crypto`,
  `Intl`, полноценные даты/локали
- Живые цифры прода: 359 пользователей, 152 регистрации на #3, **97%**
  доставки рассылок, 903 ответа квиза

## 4. Вкусные формулировки для слайдов

1. «Весь продукт — **30 флоу и 519 шагов**. Ни одного собственного сервера»
2. «**0 кода**: 133 Code step — это ~5 100 строк функций-склеек; всё
   остальное — готовые блоки платформы: таблицы, Telegram, вебхуки, таймеры»
3. «Отправка сообщения — **в десятки тысяч раз дороже** развилки
   (~0,8 с против 0,03 мс): бот проектировали так, чтобы не болтать лишнего»
4. «Правило проекта: **догадка — не факт**. Каждый лимит платформы
   проверен живым прогоном и записан — в доках 63 тысячи строк»
5. «**123 пакета работ за 5 недель**, и ни один не сдан сам себе:
   независимое ревью с чистым контекстом — наша замена юнит-тестам»
6. «Рассылка не может длиться дольше **10 минут** — так устроен движок.
   Наша живёт: курсор помнит, где остановилась» (600-секундный лимит прогона)
7. «Один клик по QR — одна запись в базе, даже если Telegram пришлёт
   апдейт дважды» (идемпотентность через store)
8. «С момента первого коммита до билета на митап — **5 недель**: 8 сентября
   начали, 17 октября на входе сканер»

## 5. Оговорки

- Числа шагов/строк — из выгрузки `flows/*.json` в репозитории (= прод)
- Цены шагов — замеры на этом инстансе после платформенных фиксов
  сентября 2026; на холодном кэше первое обращение к qadam'у дороже
- «0 кода» — инвариант проекта (ADR-0001, ADR-0030): новые сущности —
  только флоу и Code steps, свой деплой не заводится
