экспорт CSV/JSON (OWN-7, OWN-8). Кнопка «Мои ивенты» в меню — на экран

## Чек-лист готовности

- [ ] счётчики сходятся с содержимым таблиц (уникальные `telegram_id`, не строки);
- [ ] CSV открывается в Excel с целой кириллицей (UTF-8 BOM); JSON валиден;
- [ ] экспорт доступен только staff с правом на ивент (та же граница, что `load`);
- [ ] значения с `=`, `+`, `-`, `@` обезврежены от CSV-инъекции;
- [ ] кнопка меню ведёт на экран; негативные ветки меню из хвостов W34 закрыты;
- [ ] `catalog/` совпадает с живым проектом;
