## Цель

На Desktop у экранов Mini App нет способа вернуться: системного жеста нет, а
нативная кнопка Telegram включается не всегда. Правило (одобрено владельцем):
**пришёл изнутри приложения → «Назад» есть; открыл из чата напрямую → нет.**
Плюс фолбэк экранной кнопкой на клиентах без нативной.
