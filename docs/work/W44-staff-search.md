## Цель

В `#/manage/:id` → «Контролёры» добавление контролёра — поиском по имени или
`@username` с выбором тапом; права по-прежнему выдаются по `telegram_id`
(DAT-1). Подробности — [BACKLOG W44](../BACKLOG.md#w44-контролёры-выбор-из-списка-с-поиском).

## Решения владельца при взятии (2026-09-17, закрывают Q51)

- **Источник списка**: участники ивента (`registrations` → `users`) + `staff`
  чаптера; кого нет в списке — ручным вводом `telegram_id` (W36 остаётся
  запасным путём).
- **Поля и доступ**: в списке имя + `@username` (подпись для поиска),
  `telegram_id` в записи решения, в списке текстом не показываем; искать
  вправе любой staff с доступом к ивенту (та же граница, что `staff_add` в W36).
- **Поведение**: поиск от 2 символов, пустой/короткий запрос — ничего не
  показываем (отличие от прототипа, где пустой запрос показывал всех, —
  осознанно: не светить базу без запроса); лимит 20; пустой результат —
  понятный текст + подсказка ввести ID.
- **Аватары**: инициалы CSS, как в прототипе; фото из Bot API не тянем.
- **Скоуп**: только `manage-api` (новый action `staff_search`) + `Manage.tsx`;
  `tg-router` не трогаем, инвайт-ссылки не делаем (v0.2, W10).
