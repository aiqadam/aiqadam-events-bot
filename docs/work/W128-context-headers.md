## Чек-лист готовности

- [ ] «Профиль»: карточка-шапка (инициалы, ФИО, «должность, компания · город»)
      над строкой «Язык» — форма эталона (`prototypes/app.js` `renderProfile`);
- [ ] «Профиль»: «Удалить аккаунт» визуально отделена от «Сохранить»
      (заголовок «опасной зоны» / меньший вес) — защита от промаха;
- [ ] `#/feedback`: под заголовком — название события и дата (эталон `app-sub`);
- [ ] `#/ticket`: один заголовок — название события; дубль «Ваш QR для входа»
      убран или слит с ним;
- [ ] сканер: подсказка не дублируется (остаётся в нативном попапе), под
      попапом — прогресс/имя последнего отсканированного;
- [ ] регистрация вернувшегося (профиль заполнен): подпись, что согласие на
      обработку данных уже дано (W60 переспрашивать не велит) — без чекбокса;
- [ ] `node prototypes/check.mjs`, `tsc`, `npm run build` зелёные;
- [ ] тексты — `i18n/*.json`, офлайн-проверки чисты;
- [ ] `catalog/` совпадает (если менялись flow — экспорт тем же коммитом);
- [ ] независимое ревью, вердикт «замечаний нет».
