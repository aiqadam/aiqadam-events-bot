## Цель

Статическая страница `miniapp/index.html` со сканером QR (`WebApp.showScanQrPopup()`,
STF-1), которая бьёт в `checkin-api` (W8) и различимо показывает все исходы STF-4.

## Решения, принятые перед стартом

- **Q14 отложен.** `events-prod` (шаг 0.6) ещё не создан — сдвинут в BACKLOG на
  волну 6, после W15. Адресовать два окружения, второе из которых физически
  не существует, преждевременно. W7 бьёт в один `flowId` — `checkin-api`
  в `events-dev` — константой в `index.html`. Подробности —
  [OPEN-QUESTIONS Q14](../OPEN-QUESTIONS.md#q14).
- **Q19 решён: комбинация (1)+(3).** `checkin-api` отдаёт уже локализованный
  текст исхода (язык — `users.lang` контролёра из `initData`); обе статические
  страницы (`index.html`, `ticket.html`) тянут `i18n/<lang>.json` с того же
  GitHub Pages для собственных надписей (камера, подсказки, ошибки). Источник
  правды остаётся один. Подробности —
  [OPEN-QUESTIONS Q19](../OPEN-QUESTIONS.md#q19).
  Побочный эффект: `ticket.html` (W5, литеральные строки) тоже приводится
  к этой схеме в рамках W7 — тот же класс проблемы, то же решение, отдельным
  пакетом чинить нет смысла.
