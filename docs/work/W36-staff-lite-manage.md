# W36. Staff-lite — права контролёра по `telegram_id` в `manage` SPA

- **Статус**: в работе
- **Владелец**: агент
- **Волна**: v0.1 (критический путь, [ROADMAP](../ROADMAP.md#v01--порядок-работ-один-агент-последовательно))
- **Зависит от**: W32 (✅ сдан)

## Цель

**Любой staff с доступом к ивенту** (чаптер совпал, [ADR-0024](../adr/0024-staff-by-chapter-event-staff-checkin.md))
выдаёт и отзывает права контролёра **конкретного ивента**, указывая `telegram_id`
руками. Без этого пакета контролёрский опыт v0.1 не существует: полный W10
(инвайт-ссылки, одноразовые токены) отложен в v0.2. Подробности —
[BACKLOG W36](../BACKLOG.md#w36-staff-lite--права-контролёра-по-telegram_id-в-manage-spa),
дублировать не надо.

## Чек-лист готовности

- [ ] различающие прогоны **на опубликованной версии, curl'ом на `/sync`**:
      не-staff → `403`; staff другого чаптера → `403` (фикстуры `chapter_id='2'`);
      **staff этого чаптера, не автор ивента** → `200` (граница — чаптер, не автор);
      автор ивента из того же чаптера → `200`;
- [ ] повторное добавление того же активного `telegram_id` не создаёт вторую
      строку (чтение `event_staff` до/после — количество строк неизменно);
- [ ] отзыв: `revoked_at` установлен → на следующем скане `403` (STF-2);
      позитивный контроль: активный контролёр → `200` и чекин по прежним
      правилам IDM-2 (повторный чекин показывает исходное время);
- [ ] возврат прав после отзыва новой строкой работает: сканер снова `200`;
- [ ] нечисловой `telegram_id` → отказ валидации, в `event_staff` ничего не
      попало (проверено curl'ом, не UI);
- [ ] уведомление при заблокированном боте не ломает добавление
      (различающий прогон: 403 от Bot API → `event_staff` строка есть);
- [ ] меню staff-контролёра показывает кнопку «Сканер» на этот ивент
      (регресс W34 не задет; staff без будущих ивентов — кнопки нет);
- [ ] свой `telegram_id` staff добавить себе тоже может — не запрещаем:
      staff, он же контролёр своего ивента, легальный случай (решение
      зафиксировать в журнале);
- [ ] `i18n/ru.json`: новые ключи добавлены, `check-texts.py` чист,
      форма ответов совпадает с `catalog/snippets/ru-texts.md`
      (инвариант 7 CLAUDE.md);
- [ ] каталог: правки `catalog/flows/manage-api.md`, `catalog/overview.md`,
      экспорт `flows/` тем же коммитом, `check-export-secrets.sh` чист;
- [ ] независимое ревью, вердикт «замечаний нет».

## Как проверено

> Заполняется по ходу. Доказателен только прогон **после** `ap_lock_and_publish`;
> у флоу с побочными эффектами негативные проверки — `curl`ом на `/sync`
> (gotcha 11 CLAUDE.md).

- **Живой прогон на опубликованной версии (14:21Z, владелец `322876545`,
  iPhone):** `staff_list` — секция «Контролёры» открылась на `demo`;
  `staff_remove` ×2 (`999000222`, затем `8255904812`) — через UI, `event_staff`
  обновился (`revoked_at` UTC), ответы `200` с обновлённым списком,
  идемпотентность и `403` — ещё нет.
- **Живой контракт STF-2 (14:26–14:31Z, `curl` на `checkin-api/sync`
  опубликованной версии, реальный `initData` и QR-билет):** активная строка
  `event_staff` → `200 «Binali — отмечен»`; после `revoked_at` → `403 «Нет прав
  на чекин этого ивента»`; возврат прав **новой строкой** → `200 «Уже отмечен
  в 19:32»` (IDM-2 — исходное время, не перезаписано). Права переключались
  записью в `event_staff` (MCP), а не кнопкой UI `staff_add` — UI-add вживую
  ещё нет.
- Локальный харнесс `step_5/step_20/step_25` — 33/33 (права по чаптеру,
  не автор, валидация ID, идемпотентность add/remove, формат строк, кнопка).
- Остаются: `staff_add` через UI (уведомление + строка), нечисловой ID
  `curl`ом, `403` не-staff/чужого чаптера.

## Журнал

- **2026-09-15** — пакет взят. Решения до сборки:
  - **Поля `event_staff` — из живой таблицы, не из текста BACKLOG:**
    запись идёт с `granted_by`/`granted_at` (в BACKLOG написано `added_by` —
    такой колонки нет), отзыв — `revoked_at`;
  - **Имена действий** — `staff_list` / `staff_add` / `staff_remove`
    (подчёркивания: значения сравниваются в условиях ROUTER'а как строки);
  - **Одна новая ветка `staff` у `ROUTER step_8`** + вложенный ROUTER
    add/remove/остальное: гейт `step_7` (staff + чаптер) уже стоит до
    диспетчера, отдельный вход во флоу не заводится — то же касание «правлю
    ивент» (ADR-0015);
  - **Отзыв идемпотентен**: повторный отзыв активной строки не найдёт —
    возвращается `200` с текущим списком и текстом «активных прав нет»,
    а не `404` (ADR-0003);
  - **Повторное добавление активного `telegram_id`** не вставляет вторую
    строку: CODE-шаг видит активную и отвечает «уже контролёр» (idempotency);
  - **Возврат прав — новой строкой** (очистить DATE нечем, Q30); дубли
    revoked+active допускаются и считаются W12b;
  - **Уведомление** — одно сообщение в DM с inline-кнопкой `web_app` на
    сканер этого ивента (та же кнопка, что в меню W34; «кнопка-меню» из
    BACKLOG: callback на переоткрытие меню потребовал бы правки `tg-router`,
    а он в v0.1 не трогается). Целевой аккаунт ищется в `users`; не найден —
    сообщение не отправляется вовсе (loop по пустому списку), отправка —
    `continueOnFailure` (403/блокировка не ломает добавление);
  - **Список контролёров** отдаётся сервером готовыми строками
    (`manage.staff.item`: `ID <telegram_id> — контролёр с <когда>`):
    имён нет — их пришлось бы читать из `users` лишним запросом, а овнер
    только что вводил именно ID. Русский-онли (ADR-0014).

- **2026-09-15 (продолжение)** — решение владельца: единственные команды —
  `/start` и `/start <payload>` из диплинка, дальше только карточки и Mini App
  ([ADR-0025](../adr/0025-start-only-commands-ban.md)); существующие маршруты
  команд снимаются немедленно пакетом
  [W40](../BACKLOG.md#w40-убрать-команды-кроме-start) (указание владельца
  «выпили сразу», не дожидаясь W37). Для этого пакета это значит:
  - **живые прогоны — без команд.** `initData` даёт открытие Mini App кнопкой
    из карточки. Минимальный путь: `/start` → «Мои регистрации» → «Демо-ивент
    W26» → «Показать QR» — одна воронка даёт и `initData` овнера, и payload
    билета. Прежняя инструкция с `/editevent demo` отброшена.
  - **визуальная проверка секции «Контролёры»** — либо на создаваемом из меню
    ивенте («Создать ивент» — кнопка, не команда), либо в W37 вместе со списком
    `#/manage`; командой форму больше не открываем.
  - **маршруты `/editevent`/`/manage`/`/newevent` не удаляются этим пакетом**
    (они существовали до ADR-0025, удаление — W40, после того как W37 даст
    вход экраном); новых команд не добавляется ни одной.
