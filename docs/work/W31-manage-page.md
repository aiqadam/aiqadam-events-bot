## Цель

Создание и правка ивента (OWN-1…OWN-5) переезжают из чат-анкеты
`event-wizard-*` на третью страницу Mini App `miniapp/manage.html` с одним
webhook-флоу `manage-api`. Подробности и чек-лист — в
[BACKLOG.md](../BACKLOG.md#w31-страница-manage-визард-ивента-в-mini-app),
решение — [Q43](../OPEN-QUESTIONS.md#q43), [ADR-0017](../adr/0017-screen-not-message.md) п. 3.

## Чек-лист готовности

- [ ] авторизация — на сервере, по `initData` и `events.owner_id`
      **этого** `event_id`; страница решений о правах не принимает;
      доказано **различающим** прогоном: не-владелец → отказ, владелец → успех
      на одном и том же входе;
- [ ] ввод дат трактуется как Asia/Tashkent и пишется в UTC (OWN-3) —
      проверено прогоном с датой на границе суток;
- [ ] правка опубликованного шлёт уведомление **только** при изменении полей
      `notify-on-change`, с «было → стало»; правка прочих полей — молча;
- [ ] пользовательские данные на странице вставляются через `textContent`,
      в чат уходят без `parse_mode` либо экранированными;
- [ ] решение по шрифтам `manage` записано числом (ADR-0020 п. 3);
- [ ] своих цветов, кнопок и типографики нет — `grep` из чек-листа п. 3a молчит;
- [ ] гео и фото либо решены внутри страницы, либо вынесены владельцу
      явным вопросом — не урезаны молча;
- [ ] долг Mini App из круга 7 W30 (пп. 2 и 4): отказ на `ticket` — рамкой/полосой,
      а не цветом текста; у «Загрузка…» есть таймаут и «повторить», не-JSON
      ответ отделён от «нет соединения»; проверено headless-прогоном;
- [ ] `event-wizard-*` выведены из эксплуатации **после** приёмки `manage`;
      каталог и `flows/` без них, `tg-router` без их веток;
- [ ] каталог: `catalog/flows/manage-api.md`, раздел Mini App в
      `catalog/overview.md`, экспорт `flows/` тем же коммитом;
- [ ] независимое ревью, вердикт «замечаний нет»;
- [ ] `catalog/` совпадает с живым проектом.
