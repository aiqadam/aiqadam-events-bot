## Цель

Снять с горячего пути то, что осталось после [ADR-0012](../adr/0012-end-to-end-flows-instead-of-subflow-functions.md):
повторные чтения таблиц, лишние CODE-шаги, лишние сообщения `/start`.
Удалить `fn-*`-флоу, которых после W21 никто не вызывает. Привести каталог
в соответствие с живым проектом. Продолжение [Q28](../OPEN-QUESTIONS.md#q28).

## Замер «до» (2026-09-13, разложение живых PRODUCTION-прогонов)

Метод — сумма длительностей шагов по `ap_get_run`; после W17 она равна
длительности прогона (пауза ≈0).

| `registration` `/start` | `vAVCNJuF1SedAdEPBhQzh` | 7,7 с | 11 шагов, 0,75 с | 8 обращений, 3,42 с | 4 отправки, 2,98 с |

**Цены операций, замеренные, а не оценённые:**

| Операция | Цена |
|---|---|
| CODE-шаг (любой, включая тривиальный) | 57–101 мс, в среднем ~72 |
| `tables-find` / `update` / `create` | 360–560 мс |
| `store put_if_absent` | 483 мс |
| отправка сообщения через Bot API | 670–860 мс |
| `callFlow` inline hop | ~520 мс (было 1,0–1,2 с в Q28) |

**Два факта, которых в [Q28](../OPEN-QUESTIONS.md#q28) нет:**

1. **Цена чтения `tables` не зависит от объёма выборки.** 30 строк — 472 мс,
   3 строки — 531 мс. Следствие: «прочитать надмножество один раз и
   отфильтровать в CODE» почти всегда выигрывает у нескольких узких чтений.
2. **CODE-шаг не бесплатен в количестве.** Q28 оценил его в 0,06 с и назвал
   дешёвым — поштучно верно, но в `checkin-api` их 17, и это 1,25 с, 29 %
   прогона.

## Что делаем

- [ ] `registration`: три чтения `strings` → одно; два чтения `registrations` → одно;
      чтение `sessions` убрано (передаётся из `tg-router`)
- [ ] `registration`: `/start` отправляет 2 сообщения вместо 4 (правка SPEC + ADR)
- [ ] `checkin-api`: CODE-цепочки слиты, чтение `users` для языка контролёра убрано
- [ ] `my-qr-api`: CODE-цепочки слиты
- [ ] `tg-router`: `users` не переписывается без изменений; `sessions` читается
      только когда нет `start_payload`; сессия передаётся в payload
- [ ] `fn-*`-флоу, которых никто не вызывает, удалены; логика `fn-resolve-segment`
      сохранена сниппетом до удаления
- [ ] замер «после» по выборке в одном окружении, записан сюда и в ADR-0009
- [ ] `catalog/` совпадает с живым проектом
- [ ] независимое ревью, вердикт «замечаний нет»
