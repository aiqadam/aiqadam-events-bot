## Решение

- Ключи `ru.json`, идентификаторы (`event_id`, `eventId`, таблицы `events`/
  `event_staff`, файлы, якоря вне переименованных заголовков) — не тронуты.
  Только кириллические словоформы: 9 форм (`ивент/а/у/ом/е/ы/ов/ами/ам`).
- Спецзамены до общей (порядок важен): «Управление ивентами» →
  «Панель администратора», «Создать ивент» → «Новое событие»,
  «Новый ивент» (фолбэки SPA) → «Новое событие».
- Согласование рода (ивент м.р. → событие ср.р.) — явными фразами:
  «конкретный ивент» → «конкретное событие», «ближайший ивент» →
  «ближайшее событие», «ивент обязан…/был опубликован» → «событие
  обязано…/было опубликовано» и т.д. (11 фраз, плюс добор по
  `прошлый/первый/один/любой/другой/этот/каждый/следующий`). Blind-замена
  словом давала бы «событие обязан», «ближайший событие» — поймано
  ревью диффа до коммита.
- Живые флоу правятся только через MCP (`ap_update_step` полной картой `texts`
  — гоча 12, плюс комменты кода тем же вызовом), затем `validate` → `publish` →
  экспорт MCP → `flows/*.json` + `_manifest.json` + строки `migrations`
  (ADR-0021: одна строка на каждый publish — здесь 17: 15 + 2 републикации).
- Экспорт — хирургический патч (W54-прецедент): тексты строго по ключам
  65-карты, код — фразами, `reg-api`/`reg-profile` — raw-текстом (у них
  докоммитный REST-формат без сортировки ключей; JSON-перезапись дала бы
  тысячестрочный дифф). Сверка попарно: `check-texts.py` 211/0, дифф только
  intended-строки, ноль форм `ивент` в 15 файлах.
- `manage-api` живьём уже был переименован прошлой сессией (тексты, комменты
  шагов 5/7/20/25/32/42/46/50 — все новые; экспорт репозитория при этом
  старый): публикация W56 закрепляет, патч доводит снимок. В журнале прошлой
  сессии это не отражено.
- Гоча 16 (AGENTS.md): параллельные `ap_update_step` по одному флоу
  затирают друг друга — `bcast-step/step_7` и `reg-start/step_9` не легли
  с первого раза (успешные ответы, старые тексты живьём). Поймано
  независимой сверкой экспорта через субагентов, донесено поодиночке,
  републиковано. Правки одного флоу — строго последовательно.
  Родственное: частичный `sourceCode` усекает шаг (чуть не оставил
  `reg-start/step_9` трёхстрочным — восстановлен полным кодом, сверен
  чтением).
- История не переписывается: `docs/adr/*.md`, `docs/work/*.md` (кроме этого
  журнала) оставлены как есть — там термин цитирует решения и кнопки своего
  времени. Ссылки из них на переименованные якоря BACKLOG могут протухнуть —
  принято осознанно.
- `uz/en.json` — кириллицы нет, не тронуты (I18N-2 приостановлено, ADR-0014).
- SPEC.md переименован тем же вердиктом владельца (не молча: основание —
  этот журнал + вердикт 2026-09-19), отдельным коммитом от остального пакета.
