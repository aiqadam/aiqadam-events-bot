## Хвосты и блокеры

- `package: owner` — новая конвенция для изменений вне пакетов; при
  следующем изменении инстанса вне пакета писать так же.
- ПД в notes старых строк W31 (`w31-13/14`): вне пакета; `check-migrations.py`
  флагает предупреждением при каждом прогоне, чистить при следующем касании
  таблицы.
- Скрипт сверяет `publishedVersionId` и состав, но **не** содержимое
  `flows/<name>.json` с живой версией — это остаётся за `export-flows.sh`
  при выгрузке (свежесть снимка).
