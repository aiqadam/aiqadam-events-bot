## Как проверено

- сверка набора ключей скриптом → `ru` 444 / `uz` 310 / `en` 310, не хватает
  138, лишних 4 (`events.list.item`, `menu.btn.my_registrations`, `myreg.item`,
  `myreg.title` — легаси до переименования; ссылок в коде нет, только
  комментарий в `prototypes/scenarios.js`); после правки — 444/444/444;
- все 205 ключей, читаемых флоу (`{{$t[...]}}` в `flows/*.json`), в `uz`/`en`
  **уже есть** — недостающие 138 это строки Mini App (`manage` 75,
  `feedback` 17, `profile` 14, …), у них фолбэк на `ru` по каждому ключу;
- плейсхолдеры `{…}` каждого перевода сверены с `ru` скриптом → расхождений 0;
- кириллицы в `uz`/`en` не осталось (скрипт) → 0; идентичные `ru` значения —
  только языконейтральные (URL, бренды, `@username`, шаблоны из одних `{…}`);
- ключи, вызываемые из кода Mini App (`t('…')`), все есть в словаре
  (единственный «пропуск» — динамический `t('lang.btn.' + code)`, не баг);
- офлайн: `check-texts.py` 283/0, `check-commands.py` 0, `check-export-secrets.sh`
  чисто; `npm run build:dev` зелёный, `dist/i18n/*.json` — 444/444/444.
