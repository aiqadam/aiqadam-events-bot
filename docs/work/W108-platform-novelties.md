зафиксировать решение по каждому новшеству, влияющему на проект: что берём

и точечные правки канона. Живые флоу и таблицы пакет не трогает.

## Как проверено

- **Инвентаризация:** `gh pr list --repo aiqadam/qadam-flow --state all
  --json number,title,state,createdAt,labels --search "created:>=2026-09-13"`
  → 68 PR. Тела ключевых PR сняты `gh api .../pulls/N`.
- **Сборка инстанса:** MCP-схемы `ap_flow_structure` (`includeInput`),
  `ap_update_step` (`logInput`/`logOutput`/`loopCollect`/`loopExecution`),
  `ap_manage_fields` (`DECLARE_KEY`/`CLEAR_KEY`), `ap_upsert_translations`,
  `ap_list_translations` — присутствуют.
- **Табличный qadam:** `ap_get_piece_props(@aiqadam/qadam-tables,
  tables-update-record)` → проп `clear_columns` с описанием «unset a cell».
- **Subflows:** `ap_research_pieces([@aiqadam/qadam-subflows])` → экшен
  `callFlowForEach`.
- **Роутеры:** обход всех 32 `flows/*.json` — conditionless только fallback;
  живой `ap_flow_structure(reg-api)` подтверждает ветки с условиями.
- **`skip`:** живой `ap_flow_structure(reg-api)` → `step_12` =
  `skipped [SKIPPED]`; совпадает с `flows/reg-api.json` (`skip: true`).
- **Пины qadam'ов:** разбор `flows/*.json` — `tables` 0.4.5 ×156 / 0.4.6 ×20;
  `subflows` 0.4.14 ×50 / 0.4.15 ×5; `webhook` 0.1.34–0.1.37; `http` 0.12.0.
- **`bcast-run`:** разбор экспорта — cursor `limit 30` по `state = pending`,
  `pace 1s`, `callFlow` queue на следующий чанк.
- **HTTP:** один шаг, GET + `queryParams`; тела нет → #542/#541 неприменимы.
- **Переводы:** `ap_list_translations` → один платформенный тестовый ключ
  `kkkk` (не наш).
- **Mini App:** `miniapp/src/lib/api.ts` — обработки 504/503 нет (наш
  respond-стиль не задевает; вынесено в риск 5.2).

## Журнал

- **2026-09-27** — пакет взят по прямому поручению владельца в чате:
  «изучи PR за две недели, заведи один пакет по адаптации к новшествам,
  распиши детально в ADR, запуш». Заведён W108 как **ревизия**, а не
  внедрение: живые флоу не трогаем, иначе ревью-цикл смешает анализ с
  изменениями.
- **2026-09-27** — собран список 68 PR. Ключевые темы: Tables (#543, #472),
  циклы (#546), i18n (#550/#553), MCP/логи (#452, #539), P0 (#435),
  sync (#514/#533).
- **2026-09-27** — живая ревизия dev: роутеры чисты, `skip` жив,
  `clear_columns` и `callFlowForEach` доступны, переводы доступны. Это
  переводит ADR из «надо бы посмотреть» в «доступно сейчас».
- **2026-09-27** — решение: Q30 закрывается апстрим-фиксом `#543`, поэтому
  W25 разблокирован (`#420` закрыт как задумано), а уникальные ключи и
  BOOLEAN/JSON **отложены** — на них нужен аудит дублей и ревизия ADR-0003.
- **2026-09-27** — отдельно назван острый риск: write-time валидация
  `#472` серверная и применяется независимо от пина qadam'а; принимается
  только после различающего прогона (ADR-0044, п. 5.1).
- **2026-09-27** — исправлены устаревшие утверждения канона (AGENTS.md:
  «MCP не отдаёт `settings.input`», «уникальных индексов нет», «типы только
  TEXT/NUMBER/DATE/STATIC_DROPDOWN», «очистить DATE нечем», гоч 8; Q30).
