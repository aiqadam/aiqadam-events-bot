# Роли агентов

Здесь лежит **канон ролей** — обычный Markdown, без привязки к харнессу:
[dev-agent](dev-agent.md) (владелец пакета) и [review-agent](review-agent.md)
(независимый ревьюер). Протоколы ролей существуют отдельно и не дублируются:
порядок взятия и сдачи — [docs/work/README.md](../work/README.md), чек-лист
ревьюера — [docs/work/REVIEW-CHECKLIST.md](../work/REVIEW-CHECKLIST.md),
брифинг — [docs/ROADMAP.md](../ROADMAP.md#брифинг-агента-берущего-пакет).

Решение и его цена — [ADR-0029](../adr/0029-agent-roles-canon-and-adapters.md).

## Как это устроено

| Слой | Где | Что там |
| --- | --- | --- |
| Канон | `docs/agents/*.md` | поведение роли: входы, протокол, границы. Источник правды |
| Адаптер | `.opencode/agent/*.md`, `.claude/agents/*.md` | только frontmatter прав и указатель на канон. Никаких процедур |
| Проверка | `tools/check-agents.py` | канон на месте, адаптеры тонкие, запреты ревьюера на месте, имена MCP-серверов согласованы |

**Процедура, повторённая в адаптере, — дефект:** адаптеров два, и они
разъедутся. Если харнесс не умеет агентов вовсе, роль выполняется по канону:
«прочитай `docs/agents/<роль>.md` и работай по нему».

## Чего харнесс-агностика не даёт

Сила запретов у харнессов разная, и это не скрывается:

- **opencode** — запрещает конкретные инструменты (MCP-мутации) и команды
  (`git commit`/`push`, `curl -X POST`), правки — только в журнал пакета;
- **Claude Code** — только список инструментов: точные имена MCP-тулов без
  подстановок, `Edit` нельзя сузить до одного каталога;
- **Codex** и подобные — самое грубое (`sandbox_mode`), точных запретов нет.

Поэтому запреты, которые харнесс умеет закрепить, закреплены в адаптере;
остальное держится каноном и ревью. `tools/check-agents.py` проверяет
офлайн-часть: наличие канона, тонкость адаптеров, `deny` по умолчанию и
read-only allow-list у ревьюера, покрытие имён MCP-серверов из конфигов.

Новый харнесс = новый тонкий адаптер + строка в проверке. Канон не меняется.

## Контекст-файл

`AGENTS.md` — канонический контекст-файл: его нативно читают Codex, Cursor,
Gemini CLI, opencode и другие. Claude Code читает `CLAUDE.md`, поэтому тот
сделан симлинком на `AGENTS.md` — второй копии правил в репозитории нет, а
ссылки документов на `CLAUDE.md` ведут к тем же байтам. Равнодопустимая
замена — файл `CLAUDE.md` со строкой `@AGENTS.md` (импорт); она переживает
Windows-чекаут, где симлинки деградируют. `tools/check-agents.py` принимает
обе формы.
