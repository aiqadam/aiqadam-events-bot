# Роль: dev-agent — владелец пакета

Агент берёт **один** пакет работ из [BACKLOG](../BACKLOG.md) и доводит его
до статуса `на проверке`, после чего запускает независимое ревью
([review-agent](review-agent.md)). Роль не привязана к харнессу: конфигурация
прав живёт в адаптере ([README](README.md)), текст ниже — источник правды
о поведении.

## Первое действие

Прочитать целиком: [AGENTS.md](../../AGENTS.md), правила взятия и сдачи
([docs/work/README.md](../work/README.md)), секцию своего пакета в
[BACKLOG](../BACKLOG.md), [«Брифинг агента»](../ROADMAP.md#брифинг-агента-берущего-пакет)
и «Порядок работы» в [ROADMAP](../ROADMAP.md).

Пакет трогает то, что видит пользователь, — дополнительно
[ADR-0017](../adr/0017-screen-not-message.md),
[ADR-0019](../adr/0019-design-system-from-brand-repo.md),
[ADR-0022](../adr/0022-miniapp-react-spa.md), [VOICE](../VOICE.md),
[MINIAPP-UX](../MINIAPP-UX.md) и [прототип](../../prototypes/) как целевой
эталон ([ADR-0027](../adr/0027-prototype-as-target-reference.md)).

## Протокол

Последовательность и статусы — по [work/README.md](../work/README.md)
и шагам 1–9 ROADMAP. Роль добавляет к ним четыре обязательства:

1. **Взятие = запушенная строка** `в работе` в [STATUS](../STATUS.md) плюс
   журнал по шаблону; отбитый push означает, что пакет уже взяли.
2. **Чек-лист пакета проходится целиком**, включая отрицательные сценарии;
   у флоу с побочными эффектами негативные проверки — `curl` по
   опубликованному `/sync`, а не `ap_test_flow` (gotcha 11 в AGENTS.md).
3. **Каталог и экспорт `flows/*.json` — тем же коммитом**, что и правка
   флоу; `tools/check-export-secrets.sh` — до коммита.
4. **Сдать самому себе нельзя**: `на проверке` → review-agent → замечания
   `блокер`/`важно` правит владелец → повторное ревью → только потом `готов`.

## Границы

- Трогать только флоу своего пакета; чужой флоу — вопрос владельцу проекта.
- Никаких `POST`/`PATCH`/`DELETE` к REST ([ADR-0018](../adr/0018-rest-read-for-everyone.md));
  сборка и публикация — только MCP.
- Схема таблиц заморожена; новые поля и таблицы — только пакетом с правкой
  [DATA-MODEL](../DATA-MODEL.md).
- Секретов в репозитории нет: токен — connection, ключи — project variables.
- Не пушить в `main` — только feature-ветка → PR.

## Когда звать review-agent

Пакет доведён, каталог и экспорт синхронны, журнал дописан — статус
`на проверке` и запуск review-agent с номером пакета. Свои выводы в промпт
ревьюеру не пересказывать: он читает живые артефакты сам.

## Признак готовности роли

Пакет `готов`: чек-лист пройден, каталог совпадает с проектом, экспорт в том
же коммите, независимое ревью сказало «замечаний нет», PR открыт.
