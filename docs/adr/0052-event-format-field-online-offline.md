# 0052. Формат события — явное поле; ссылка трансляции необязательна

**Статус:** принято, 2026-09-29, решением владельца. **Отменяет** признак
онлайна из [ADR-0051](0051-online-event-link-instead-of-qr.md) п. 1 (непустой
`online_url` = онлайн) и неявное «онлайн ≡ нет точки» из [Q63](../OPEN-QUESTIONS.md#q63);
остальные пункты ADR-0051 (QR для онлайна не выдаётся, ссылка в билете и
напоминаниях, публичный каталог ссылку не отдаёт, очистка — хвост) сохраняются.
Уточняет [SPEC](../SPEC.md) OWN-1/OWN-18. Часть пакета [W67](../work/W67-online-event-link.md).

## Контекст

[ADR-0051](0051-online-event-link-instead-of-qr.md) ввёл `online_url` и сделал
непустую ссылку **признаком** онлайна. Решение владельца 2026-09-29 (ответ на
вопрос о пороге): «когда я её укажу, ссылку» — ссылку организатор может задать
**позже**, уже после публикации и регистрации. При прежнем признаке это ломается:
пока ссылки нет, событие выглядит офлайном и билет получает QR — то есть
исчезает само правило «для онлайна QR не генерируется».

Форма Mini App переключатель «Онлайн/Офлайн» уже рисовала, но в таблице он не
хранился ([SPEC](../SPEC.md): «формат отдельным полем не хранится»), поэтому
отличить «онлайн без ссылки» от «офлайн» было нечем.

## Решение

1. **`events.format`** — `STATIC_DROPDOWN` `online` \| `offline`
   ([DATA-MODEL](../DATA-MODEL.md)). Это единственный признак формата; пусто у
   старых записей читается как офлайн, кроме непустой `online_url` (совместимость).
   Переключатель формы теперь пишется на сервер.

2. **`online_url` — необязательная ссылка** на онлайн-событии, а не признак.
   Может появиться позже; у офлайна не используется. Валидация: если задана —
   `https://`, ≤500 символов.

3. **QR для онлайна не выдаётся никогда** (`my-qr-api` по `format`). Ссылки нет —
   `{ok, online:true, url:""}`, билет показывает «ссылка появится позже», а не QR.
   Есть ссылка — кнопка «Открыть трансляцию».

4. **Напоминания 24 ч / 2 ч** для онлайна идут без строки «Адрес: »; кнопка
   «Открыть трансляцию» — только когда ссылка задана.

5. **`format` и `online_url` входят в `notify-on-change`** (OWN-5): публикация
   ссылки позже или её смена уведомляет зарегистрированных.

## Следствия

- Схема `events` получила ещё одно поле — отдельным решением владельца.
- Существующие записи `events` бэкфиллены `format` (адрес/точка есть → офлайн,
  иначе онлайн); изменения данных — строка `migrations`.
- Хвост ADR-0051 п. 5 остаётся: при переводе офлайн → онлайн старые
  `address`/`lat`/`lon` автоматически не очищаются (Tables: пусто = «не менять»).
- [Q63](../OPEN-QUESTIONS.md#q63) закрывается: формат теперь выражен явно.
