# 0046. Город в онбординге: «Вы из Ташкента?» вместо списка городов

**Статус:** принят 2026-09-27 владельцем (решение по прямому запросу в чате,
без предварительного пакета BACKLOG). Уточняет городской шаг
[ADR-0043](0043-shorter-onboarding.md) (п. 3 и итоговый путь), остальное
ADR-0043 — число и порядок экранов, согласие раньше первого поля, гейт
`profile_completed_at` — не трогает.

## Контекст

ADR-0043 (и [ADR-0032](0032-onboarding-first-touch-profile.md) до него) задал
городской шаг так: вопрос «Из какого вы города?» и две кнопки-города
«Ташкент»/«Алматы» плюс «Написать» для свободного ввода. Владелец
2026-09-27 предложил упростить: спрашивать «Вы из Ташкента?» кнопками
«Да»/«Нет», а на «Нет» давать свободный ввод города.

Причины:

- короткий список городов произволен (почему именно эти два?) и не
  масштабируется — любой следующий город всё равно уходит в «Написать»;
- вопрос да/нет читается легче, чем выбор из трёх кнопок, и честнее: для
  большинства участников Ташкент — ожидаемый ответ в один тап;
- свободный ввод и так был общим случаем — он остаётся, но теперь это
  единственный путь для «не Ташкент», без промежуточной кнопки.

## Решение

1. **Карточка города — вопрос да/нет.** Текст `onb.ask_city` —
   «Вы из Ташкента?», кнопки `common.btn.yes`/`common.btn.no` →
   `ob:city:yes`/`ob:city:no`. Списка городов и кнопки «Написать»
   (`onb.btn.write`) на карточке больше нет.
2. **«Да» — сразу `finish`** с городом `Ташкент` (как раньше давала кнопка
   «Ташкент»): город — последнее поле, выбора достаточно для записи профиля
   и регистрации.
3. **«Нет» — свободный ввод.** `ob:city:no` ведёт на карточку
   `onb.ask_city_input` («Напишите ваш город.»), шаг `ob_await_city`; текст
   пользователя становится городом и ведёт в `finish`.
4. **Старые колбэки `ob:city:Tashkent`/`ob:city:Almaty`/`ob:city:write`
   остаются алиасами** на один релиз: карточка, отправленная до правки, может
   ещё лежать в переписке, а необработанный колбэк даёт молчание. Это
   совместимость, а не рабочий путь; из UI они недостижимы.

## Следствия

- **PAR-8 не трогается по составу:** город по-прежнему обязателен и
  собирается до записи; меняется только способ вопроса.
- **PAR-1 не трогается:** согласие пишется веткой `consent` при `ob:agree`
  до первого поля ПД, город — последний шаг.
- **Цена, названная прямо:** не-ташкентец делает лишний тап («Нет») и обязан
  набрать город текстом, а быстрая кнопка «Алматы» пропадает. Митигация —
  свободный ввод остаётся тем же, что и был за «Написать»; при необходимости
  город можно поправить в табе «Профиль».
- **Вопрос «вы из Ташкента?» смещает ответ:** часть пользователей нажмёт
  «Да» не задумываясь. Цена принята: город правится в профиле.
- **Мёртвый ключ** `onb.btn.write` («Написать») остаётся в `i18n/*.json` как
  архив корпуса (прецедент — `onb.review` в ADR-0043); живые флоу его больше
  не читают.

## Альтернативы

- **Оставить список, добавив ещё города** — отклонено: список не
  масштабируется и всё равно упирается в «Написать».
- **Город свободным вводом сразу, без вопроса** — отклонено: лишает
  ташкентцев одного тапа, ради которого вопрос и задаётся.
