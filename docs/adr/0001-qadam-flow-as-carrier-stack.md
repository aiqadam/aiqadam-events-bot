# 0001. Qadam Flow как несущий стек, цель — 0 кода

**Статус:** принято, 2026-09-08.

## Контекст

Нужен Telegram-бот событий: ивенты, регистрации, QR-чекин, рассылки.
Очевидный путь — обычный сервис (aiogram / grammY) с своей БД и деплоем.
В организации такой уже есть — `aiqadam/aiqadam-telegram-bot`.

При этом у AI Qadam есть собственная платформа автоматизации — Qadam Flow
(форк Activepieces, MIT-ядро без enterprise-гейтов), развёрнутая на
<https://app.flow.aiqadam.org>.

## Решение

События собираются **целиком на Qadam Flow**. Своего сервиса, своей БД,
своего деплоя у проекта нет.

Допустимый инструментарий:

- флоу и subflow-«функции» (`subflows` qadam);
- **Code steps** внутри флоу — но только как чистые функции;
- core-qadam'ы: `tables`, `crypto`, `store`, `schedule`, `webhook`, `http`, `csv`, `qrcode`, `delay`;
- `community/telegram-bot` для Bot API.

Кастомный qadam в `packages/qadams/custom/` **не заводим** — это форк платформы
со своим релизным циклом, то есть тот же собственный код, только дороже.

Единственное исключение — статическая страница Mini App: `showScanQrPopup()`
требует клиентского JS, обойти это нечем.

## Следствия

Хорошее:

- нет своего деплоя, БД, CI и дежурства по сервису;
- события становятся живым доказательством, что на Qadam Flow можно строить
  продуктовые вещи, — платформа, которую организация продвигает, обкатывается на себе;
- изменения делает не только тот, кто пишет код.

Плата — принимается осознанно:

- **рассылка** упирается в `FLOW_TIMEOUT_SECONDS = 600`, а Code step не умеет
  перезапускать сам себя. Нужны чанки, курсор в `store` и добирающее расписание;
- **визард ивента** превращается в ветвление по `sessions.step` и читается хуже FSM;
- **юнит-тестов нет** в привычном виде; проверяемость держится на чек-листах приёмки;
- отладка живёт в логах прогонов платформы, а не в стектрейсе;
- мы принимаем лимиты платформы как свои: её таймауты, её песочница, её доступность.

Пересматривать решение стоит, если рассылки перестанут укладываться в лимиты прогона
или визард станет неподдерживаемым. Оба симптома наблюдаемы заранее, а не внезапны.
