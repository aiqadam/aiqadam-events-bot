# 0012. End-to-end флоу вместо subflow-функций

**Статус:** принято, 2026-09-12. Решение владельца проекта по итогам замеров
[Q28](../OPEN-QUESTIONS.md#q28) и [W20](../work/W20-idempotency-on-atomic-primitives.md).

**Сужает** [ADR-0001](0001-qadam-flow-as-carrier-stack.md) (subflow-функции
перестают быть рабочей практикой) и **отменяет локальность криптографии** из
[ADR-0010](0010-unsandboxed-code-step-for-crypto.md). Реализация — [W21](../BACKLOG.md#w21-перевод-флоу-на-end-to-end).

## Контекст

Замеры живого пути (W20) разложили горячий путь по типам шагов:

| Как вызвать | Цена одного вызова |
|---|---|
| `callFlow` в режиме `queue` | ≈ 2,3 с |
| `callFlow` в режиме `inline` | ≈ 1,0–1,2 с |
| CODE-шаг в том же флоу | ≈ 0,06 с |

Разложение для inline — не оценка: `fn-fmt-time` собственным прогоном 0,5 с,
он же как вызов из `fn-event-card` 1,5 с; `fn-event-card` собственным прогоном
4,5 с, как вызов из `registration` 5,71 с.

На вызовы subflow приходится **70 %** прогона (`registration` `/start` —
12,3 с из 17,5 с; `my-qr-api` — 89 %; `checkin-api` — 76 %). Переход на
`inline` (W17) снял диспетчеризацию, но оставил ~1 с на вызов. Все прочие
рычаги, посчитанные в Q28, дают единицы секунд и тонут в разбросе инстанса
(±20 %).

## Решение

**Каждый флоу реализует свой сценарий end-to-end и не ходит в другие флоу.**

1. **`tg-router` только маршрутизирует.** Он определяет, куда послать апдейт,
   и передаёт управление. Обработчик дальше ни в кого не ходит.
2. **Переиспользуемая логика встраивается в тело флоу** CODE-шагами и
   шагами qadam'ов, а не выносится в subflow. Это не нарушает ADR-0001:
   там Code steps как чистые функции — разрешённый инструмент, а
   subflow-функции были в списке допустимого, а не обязательного.
3. **Канон живёт в каталоге.** Для каждого переиспользуемого куска в
   `catalog/snippets/` лежит эталонная реализация и список флоу, которые её
   встраивают. Каталог перестаёт только описывать реальность и начинает
   **предписывать**: копия обязана совпадать с эталоном побайтово.
4. **Исключений нет, включая криптографию.** HMAC переезжает в тела флоу.

## Цена

Названа прямо, потому что решение принято с ней, а не вопреки ей.

- **Дублирование логики.** Одна правка эталона — правка во всех копиях.
  Забыли копию — поведение разъехалось.
- **Криптография в нескольких местах.** Отменяет то, ради чего ADR-0010
  сводил HMAC в узкие места. Существенно смягчает риск то, что **дрейф копий
  не бывает тихим**: QR подписывается в одном флоу, а проверяется в другом,
  поэтому расхождение ломает скан громко; расхождение в проверке `initData`
  означает «все контролёры отклонены» — тоже громко. Тихой деградации,
  при которой всё зелено, а секрета нет, эта схема не создаёт — в отличие
  от пустого ключа из [Q25](../OPEN-QUESTIONS.md#q25), который остаётся
  отдельным риском.
- **Толстые флоу.** `registration` уже 77 шагов. Править их через MCP дорого,
  пока открыт [#411](https://github.com/aiqadam/qadam-flow/issues/411):
  шаги `tables`/`store`/`telegram-bot` меняются только пересозданием.
- **Каталог становится критичным.** Расхождение каталога с флоу раньше было
  неудобством, теперь — источником дефектов.

## Что остаётся в силе

- ADR-0001 целиком: свой сервис по-прежнему нельзя, Code step — чистая функция
  без сети и записи в БД.
- ADR-0010 в части «`node:crypto` в Code step разрешён» — отменяется только
  требование держать его в трёх выделенных флоу.
- ADR-0011 (идемпотентность на атомарных примитивах) — не затрагивается.
- Инварианты SPEC (STF-2, IDM-1…IDM-4, PAR-1/2, I18N-2) не меняются и
  доказываются теми же различающими прогонами.

## Альтернативы

- **Оставить как есть, ждать апстрим.** Цена вызова — их накладной расход,
  и её могли бы срезать на своей стороне. Отвергнуто: сроки чужие, а
  ускорение нужно сейчас. Вопрос апстриму всё равно заводится — если его
  починят, схема из этого ADR станет просто ещё быстрее.
- **Встроить всё, кроме криптографии.** Давало бы `checkin-api` ≈5,8 с
  вместо ≈3,8 с, сохранив подпись в одном месте. Отвергнуто владельцем:
  зоопарк флоу ради двух секунд не окупается, а дрейф крипты громкий.
