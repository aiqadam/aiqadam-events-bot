строки, и git сливает их без конфликтов. Подробности каждого пакета —
в его журнале `docs/work/WNN-*.md` ([правила ведения](work/README.md)).

только после вердикта «замечаний нет». Сдать пакет самому себе нельзя —
[правила](work/README.md#цикл-сдачи).

формальность: `{{connections['<id>']}}`, использованный в `fn-verify-init-data`
как обычные данные (не как `auth` шага), не давал тот же токен бота, что
использует внутренняя авторизация того же connection для настоящих вызовов
Bot API — `checkin-api` отклонял бы **всех** контролёров, включая настоящих.

([ADR-0008](adr/0008-bot-token-as-variable-not-connection-template.md)); чинит
сразу все вызывающие `fn-verify-init-data` (`registration`, `my-qr-api`,

Оба закрыты дифференцирующими прогонами (стафф другого ивента, отозванный

независимо воспроизвёл оба сценария заново, включая позитивный контроль
(владелец его не делал), — вердикт «замечаний нет». Пакету поставлен статус
`готов`.
