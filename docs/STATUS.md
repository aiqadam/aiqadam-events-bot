# Статус проекта

Индекс работ. **Одна строка на пакет** — так параллельные агенты правят разные
строки, и git сливает их без конфликтов. Подробности каждого пакета —
в его журнале `docs/work/WNN-*.md` ([правила ведения](work/README.md)).

Статусы: `не начат` · `в работе` · `заблокирован` · `на проверке` · `готов`.

`на проверке` — пакет доведён и ждёт **независимого ревьюера**; `готов` ставится
только после вердикта «замечаний нет». Сдать пакет самому себе нельзя —
[правила](work/README.md#цикл-сдачи).
