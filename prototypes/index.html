AI Qadam Events — UI-прототип

прототип, не продукт

Кликабельный прототип двух поверхностей: мок чата Telegram и мок Mini App. Сначала — построенное (v0.1: гость / овнер / контролёр), затем — предложения v0.2 (W13/W14/W38/W39), помеченные бейджем «предложение». Инстанс не трогается, данных на сервере нет (ADR-0026, пакет W41).

Матрица «роль × вход × функция»

ГостьPAR-1…PAR-6

Вход — deep link ?start=e<id> из ссылки регистрации.

  • Карточка ивента + согласие на ПД — одним экраном (ADR-0017)
  • Согласие на рассылку — отдельный необязательный шаг (PAR-2)
  • Билет с QR в Mini App (#/ticket)
  • Напоминания 24ч / 2ч, послесловие — W12
Овнер (staff)OWN-1…OWN-15

Вход — карточка меню /start → «Создать ивент» (кнопка web_app).

  • Создание и правка ивента в #/manage (OWN-1…OWN-5)
  • Ссылка-приглашение после публикации (OWN-6, W37)
  • Контролёры ивента по telegram_id (W36)
  • Участники, счётчики, экспорт — W13
  • Рассылка пересылкой — W14
КонтролёрSTF-1…STF-4

Вход — кнопка «Сканер чекина» в меню (ближайший будущий ивент) → #/scan.

  • Сканер не закрывается между людьми (STF-1)
  • Четыре исхода: успех / уже отмечен / нет регистрации / другой ивент (STF-4)
  • Права проверяются по конкретному event_id (STF-2)
Staff + контролёрсовмещение ролей

Одна строка в staff (чаптер) и строка в event_staff (ивент).

  • Меню показывает все четыре кнопки (порядок фиксирован, W34)
  • Права на правку — по чаптеру, на чекин — по ивенту (ADR-0024)

Состояния, которые ломают экран

401 — устаревший initData

«Данные Mini App устарели — переоткройте приложение» (окна по флоу, Q49)

403 — нет прав

«Нет прав на чекин этого ивента» / «Нет прав на правку» (STF-2, ADR-0024)

Нет связи

«Нет соединения. Проверьте сеть и повторите.» + кнопка «Повторить»

Сервер ответил не-JSON / ошибка в ответе

«Сервер ответил неожиданно. Повторите чуть позже.» — различимо от нет-связи

Светлая / тёмная тема

Из Telegram.WebApp.colorScheme; переключатель справа внизу

Safe Area (инсеты)

Контент под шапкой/жестовой зоной — вариант с инсетами на экранах (Q48 живым девайсом не закрывается)

Бейдж требование — экран построен в v0.1; предложение — пакет v0.2 (W13/W14/W38/W39), решения по нему ещё нет.
