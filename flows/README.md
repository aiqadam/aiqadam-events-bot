# Экспорт флоу

Здесь лежат шаблоны **опубликованных** флоу проекта, снятые
`GET /api/v1/flows/:id/template` — [ADR-0018](../docs/adr/0018-rest-read-for-everyone.md)
п. 3. Смысл один: `settings.input` PIECE-шагов (URL, cron, таймзоны, `format`,
порядок аргументов `hmac-signature`) виден в диффе PR, а не только тому, кто
специально сходил в REST.

## Правила

- **Руками эти файлы не правятся никогда.** Они машинные. Правка флоу идёт
  через MCP, затем снимается новый снимок.
- **Обновляются тем же коммитом, что и изменение флоу** (ADR-0018 п. 5).
  Протухший снимок хуже отсутствующего: по нему принимают решения.
- **Это снимок, а не реальность.** Ревьюер по-прежнему сверяет каталог
  с живым проектом через MCP.
- Экспорт отдаёт **опубликованную** версию. Прогоны `TESTING` исполняют
  draft — равенство draft и published доказывается процедурой (публикация,
  затем прогон, без правок между), а не этим файлом.

## Как снять и как проверить

```bash
tools/export-flows.sh              # все флоу проекта
tools/export-flows.sh checkin-api  # или только нужные
tools/check-export-secrets.sh      # ОБЯЗАТЕЛЬНО перед коммитом
```

`check-export-secrets.sh` возвращает ненулевой код, если в экспорте нашлись
паттерн токена Telegram или hex-строка ≥32 символов, а также если из экспорта
пропали ссылки `{{variables['...']}}` / `{{connections[...]}}` — последнее
значит, что форма выгрузки изменилась и «ноль совпадений» больше ничего
не доказывает.

Проверка **повторяемая, а не сделанная один раз**:
[Q38](../docs/OPEN-QUESTIONS.md#q38) зафиксировал поведение текущего образа
платформы, а не гарантию на будущее. Секрет, уехавший в историю git, не
откатывается удалением файла — он откатывается ротацией `BOT_TOKEN`
и `QR_SIGNING_KEY`.

## Ключ платформы

В репозитории его нет и не будет. Скрипт берёт ключ из `QADAM_API_KEY`, иначе
из macOS Keychain (сервис `aiqadam-events-bot:qadam-flow-api`), и передаёт
в `curl` по stdin — ключ не попадает ни в вывод, ни в `ps`, ни в историю
оболочки. Агенту Claude Code для чтения Keychain нужно разрешение
`Bash(security find-generic-password:*)` в `.claude/settings.local.json`.
