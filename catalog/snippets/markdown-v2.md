# Эталон: экранирование MarkdownV2

Копия обязана совпадать с этим эталоном побайтово
([ADR-0012](../../docs/adr/0012-end-to-end-flows-instead-of-subflow-functions.md) п. 3).
Общего subflow здесь быть не может — флоу не ходят в другие флоу.

```js
const esc = (v) => String(v === undefined || v === null ? '' : v)
  .replace(/\\/g, '\\\\')
  .replace(/([_*\[\]()~`>#+\-=|{}.!])/g, '\\$1');
```

## Почему именно так

- **Обратный слэш экранируется первым.** Если сделать его последним, он
  удвоит слэши, добавленные предыдущей заменой, и текст развалится.
- **18 символов** — полный список из Bot API (`_ * [ ] ( ) ~ ` > # + - = | { } . !`).
  Неполный список хуже отсутствующего: `400` от Telegram означает **молча
  потерянное касание**, а не видимую ошибку.
- Экранируются **пользовательские данные**, а не наша разметка. `*` вокруг
  заголовка ставится снаружи: `'*' + esc(title) + '*'`.

## Где используется

| Флоу | Шаг |
|---|---|
| `reg-start` | CODE «build card: событие + вопрос ПД» |
| `reg-consent-pdn` | CODE «card text: зарегистрирован + вопрос о рассылке», CODE «card text: отказ от ПД» |
| `reg-consent-mkt` | CODE «тексты: финальная карточка и билет» |
| `reg-afterword` | CODE «текст послесловия + ближайшее событие» |

## Где НЕ используется и почему

Служебные сообщения (`manage-api`) идут с `format: "None"`: текст состоит из наших
строк и подставленных значений без разметки, а `None` снимает весь класс
ошибок экранирования.

## Проверено

Прогоном на событии, название и адрес которого собраны из опасных символов:

```
W28: карточка-экран (пилот) — тест.
Ташкент, ул. Проверочная, 1 (2-й этаж)
точка. дефис-скобки (вот так) + плюс = равно | труба #решётка !восклицание _подчёрк *звёздочка
```

Telegram принял сообщение (`200`) и вернул `entities` с `bold` на заголовке
и `text_link` на ссылке карты — то есть разметка сработала, а данные внутри
неё остались текстом.

**`format` задаётся явно в каждом шаге** отправки и редактирования
([ADR-0017](../../docs/adr/0017-screen-not-message.md) п. 4): у
`edit_message_text` умолчание пропа — `MarkdownV2`, и шаг без явного
`format` меняет разметку молча.
